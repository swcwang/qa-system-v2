# Q&A System V2

Semantic search and AI-powered Q&A system for political discussions.

## Features
- Semantic topic discovery
- Panelist-focused search
- AI-generated responses with source citations
- Episode linking and context

## Usage
Select a panelist to see their most discussed topics, then ask questions about their views or political positions.
